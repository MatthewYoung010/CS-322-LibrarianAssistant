Hello and welcome the librarian assistant.

In order to run this you will need to have python installed and have the following libraries: sqlite(which should already come installed with python), flask, flask_cors, requests, pillow (PIL), tkinter (should also already be apart of python)

Then you will need to start running the server by going to server.py and running the python file.

After the server is running open another tab for the terminal and run the LibraryUI.py file and a application window should pop up.

Then using the UI buttons you can siwtch between the books and memebers and execute various commands.
